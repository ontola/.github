# Ontola

We're a software company that makes open technology for a resilient web. We're working on:

- [Atomic Server](https://github.com/ontola/atomic-server), an all-in-one workspace built on the Atomic Data spec we designed.
- [SearchLauncer](https://github.com/ontola/searchlauncher), an android launcher with a keyboard and a browser, for productivity geeks. 
- [OpenBesluitvorming](https://github.com/ontola/openbesluitvorming), a search engine & API for all governmental decision making documents in the Netherlands.

In the past, we've worked on the Argu.co e-democracy SAAS platform ([open source](https://github.com/ontola/argu)) and on the Solid project (in the [DexPod](https://github.com/ontola/dexpod), as on various libraries).
